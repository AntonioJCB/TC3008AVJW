# Contributing

## Branches

Use the following branch naming convention:

- `feature/<name>`
- `fix/<name>`
- `refactor/<name>`
- `test/<name>`
- `docs/<name>`

Do not work directly on `main`.

## Commits

Use Conventional Commits:

- `feat:`
- `fix:`
- `test:`
- `refactor:`
- `docs:`
- `chore:`

## Pull Requests

Each change should:

- Have a related issue
- Be submitted through a Pull Request
- Be tested locally
- Use `Closes #<issue-number>`
